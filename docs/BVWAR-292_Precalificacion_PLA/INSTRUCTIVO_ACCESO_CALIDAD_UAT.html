2. Paso a Paso para Iniciar Sesión

  1. Abrir el enlace: Ingrese a https://vimenca--calidad.sandbox.my.salesforce.com.
  2. Digitar su Usuario: Ingrese su usuario con el sufijo .calidad (ejemplo: cmpou@bv.com.do.calidad o lreynoso@bv.com.do.calidad).
  3. Digitar su Contraseña: Coloque exactamente la misma clave que utiliza para ingresar a Salesforce Producción.
  4. Verificación de Seguridad: Si se lo solicita, ingrese el código de confirmación recibido por correo o Authenticator.
  5. Consultar los Informes PLA: Diríjase a la pestaña Informes > Todas las carpetas > carpeta Reportes PLA / Cumplimiento.
