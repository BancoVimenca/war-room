# war-room

Repositorio oficial bajo arquitectura **Salesforce DX (Source Format)** gobernado por **KeyHub & Keystone Context Engine**.

## 🏗️ Estructura
- `force-app/main/default/`: Metadatos de Salesforce (Apex, LWC, Objetos).
- `manifest/package.xml`: Manifiesto de componentes.
- `sfdx-project.json`: Configuración SFDX.
